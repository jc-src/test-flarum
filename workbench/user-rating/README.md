# User Rating

![License](https://img.shields.io/badge/license-GPL-1.0-or-later-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/jcsrc/user-rating.svg)](https://packagist.org/packages/jcsrc/user-rating) [![Total Downloads](https://img.shields.io/packagist/dt/jcsrc/user-rating.svg)](https://packagist.org/packages/jcsrc/user-rating)

A [Flarum](https://flarum.org) extension. User Rating Flarum Extension

## Installation

Install with composer:

```sh
composer require jcsrc/user-rating:"*"
```

## Updating

```sh
composer update jcsrc/user-rating:"*"
php flarum migrate
php flarum cache:clear
```
